Detailed Description

The SeafEnqueuerProtocol protocol defines methods for a file uploader in the Seafile application.

Starts the upload process.

◆ estimatedUploadSizeInBytes

- (long long) estimatedUploadSizeInBytes

Calculate the estimated upload size in bytes for the current sync operation.

This method calculates the estimated upload size in bytes by summing up the sizes of all files that have changed since the last synchronization in the specified source folder.

Returns
The estimated upload size in bytes.
