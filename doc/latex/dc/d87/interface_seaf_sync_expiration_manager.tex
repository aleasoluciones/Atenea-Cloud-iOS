\doxysubsection{Detailed Description}
Manages the expiration of synchronization logs in Seafile. 

The \doxylink{interface_seaf_sync_expiration_manager}{Seaf\+Sync\+Expiration\+Manager} class is responsible for calculating the expiration date of synchronization logs based on the configured duration and removing the expired logs from the cloud repository. It utilizes the \doxylink{interface_seaf_sync_expirator_factory}{Seaf\+Sync\+Expirator\+Factory} to get the appropriate expirator based on the provided settings.
