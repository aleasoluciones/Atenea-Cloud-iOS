\doxysubsection{Detailed Description}
Factory for creating synchronization expirators. 

The \doxylink{interface_seaf_sync_expirator_factory}{Seaf\+Sync\+Expirator\+Factory} class is responsible for creating instances of classes conforming to the \doxylink{protocol_seaf_sync_expirator_protocol-p}{Seaf\+Sync\+Expirator\+Protocol}. It provides a method to get the appropriate expirator based on the provided synchronization settings.
