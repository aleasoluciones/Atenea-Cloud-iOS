The \doxylink{protocol_seaf_sync_expirator_protocol-p}{Seaf\+Sync\+Expirator\+Protocol} protocol defines the methods required for handling synchronization expiration. Classes conforming to this protocol are responsible for implementing the logic to expire synchronization data.
